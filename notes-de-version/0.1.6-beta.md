## P-Flow 0.1.6 bêta : patch 6

### L'essentiel
- **Importer** : un tableau (Excel / CSV) ou le relevé de ta banque, dans Réglages → Mes données. Ce qui est déjà noté est reconnu, rien en double.
- **Catégories** : chaque dépense est rangée toute seule (Logement, Courses…) ; touche l'étiquette pour corriger.
- **Chaque semaine** : nouvelle fréquence dans le +.
- **Brouillon** : ferme le + pour aller voir ailleurs, ta saisie t'attend en bas.

### Aussi dans cette version
- Rappel du solde : les jours choisis, l'appli te demande ton solde (Réglages).
- Visite guidée en 1 minute (Réglages → Revoir le didacticiel).
- Nouvelle icône et nouveau logo.
- Sans réseau, un bandeau le dit ; export tableur aussi sur Android.
- Fenêtres en verre, animations plus douces et petites corrections.

### Installer
- **Android** : Réglages → À propos → Mises à jour. **PC et iPhone** : recharge la page.
- Rien n'est effacé : mets à jour tous tes appareils.
